# Read-only live drift review — approval required before execution

`LIVE_DRIFT_READONLY.sql` is prepared separately from every deployment wrapper. It uses REPEATABLE READ READ ONLY, catalog SELECTs, bounded timeouts and ROLLBACK; it calls no financial RPC and takes no explicit table locks. It must not be concatenated with wrapper SQL. Read-only still consumes resources; stop on timeout and arrange a quieter observation window rather than increasing limits silently. Output includes complete function definitions and migration source arrays and belongs in private evidence storage, not git. No production query was executed in this task.

Before any approved run, independently bind the connection to project `xbvenkfmesugrbjuufyw` through the control plane and connection record. Database name/current_user alone cannot prove project identity. Record endpoint reference (redacted), observer, UTC, server version and tool version/help. Use `psql -X -v ON_ERROR_STOP=1 -f LIVE_DRIFT_READONLY.sql` only with an explicitly approved connection; no production connection string is supplied here. Do not copy approval GUC values or run a wrapper to discover drift.
